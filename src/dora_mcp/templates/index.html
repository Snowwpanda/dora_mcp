DORA MCP Server

Search and retrieve publication abstracts from the DORA (Digital Object Repository for Academia) database using AI assistants or a plain REST API.

Interactive API docs: Try all endpoints directly in the browser → __BASE_URL__/docs (Swagger UI)

What is MCP?

The Model Context Protocol (MCP) is an open standard that lets AI assistants like Claude or Copilot call external tools and data sources in a structured, secure way. Instead of copying data into a prompt, the AI asks the MCP server in real time — the server runs the query and returns the result. MCP uses JSON-RPC 2.0 over HTTP.

This server exposes two tools over MCP:

ToolWhat it does
search_publicationsSearch DORA by keyword or author name (returns up to 20 results by default)
get_publication_abstractFetch the abstract for a publication by ID or URL

Connect from Microsoft Copilot Studio

Copilot Studio supports MCP Streamable transport (SSE is deprecated since August 2025). Official docs →

Prerequisite: Enable Generative orchestration in your agent settings before adding MCP tools.
  1. Open your agent → Tools page → Add a tool → New tool → Model Context Protocol
  2. Fill in:
    • Server name: DORA Publications
    • Description: Search and retrieve abstracts from the DORA scientific publications repository
    • Server URL: https://dora-mcp-xrtnba.fly.dev/mcp
    • Authentication: None
  3. Select Create, then Add to agent.

Alternatively, import /api/openapi-copilot-studio.yaml as a custom connector via Power Apps (Add a tool → New tool → Custom connector → Import OpenAPI file).
